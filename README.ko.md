# Chess Studio

**🇺🇸 [English documentation](README.md)**

Stockfish 18을 내장한 오프라인 체스 GUI — 대국하고, 실시간 코칭을 받고,
chess.com 스타일로 게임을 리뷰하고, 내가 저지른 실수를 나만의 전술
트레이너로 만들어 줍니다. 계정도, 네트워크도, 설치 과정도 필요 없습니다.

**▶ [최신 Windows 빌드 다운로드](https://github.com/wogur110/chess-game/releases/latest)**
— zip을 풀고 `ChessStudio\ChessStudio.exe`를 실행하세요.

```bash
# …또는 소스에서 실행 (Linux/Windows)
pip install -r requirements.txt
python download_stockfish.py   # 최초 1회, ~110 MB; 이후 완전 오프라인
python main.py
```

## 기능

### 대국
- **진영별로 사람/AI 선택** — 사람 vs AI, AI vs AI(일시정지 가능), 사람 vs
  사람 모두 지원. 대국 중에도 언제든 바꿀 수 있고, 보드는 내 진영이 아래로
  오도록 자동으로 뒤집힙니다.
- **10단계 난이도** (~800 Elo → 3200+), **진영별로 독립 설정** 가능. 기본값은
  레벨 7 (마스터 · 2300).
- **대국 중 실시간 분석** — 보드 옆 승률 바와 두는 대로 인식되는 오프닝
  이름(ECO). 엔진 추천 수 3개(화살표 + 확률)는 일반적인 대국 경험을 위해
  **기본적으로 꺼져 있고**, "추천 수" 체크박스를 켜면 표시됩니다. 분석
  엔진은 난이도와 무관하게 항상 최대 성능으로 동작합니다.
- **게임 라이브러리** — 끝난 게임은 `saves/library/`에 PGN으로 자동
  보관됩니다. 라이브러리 탭에서 목록(플레이어, 결과, 오프닝)을 보고 어떤
  게임이든 대국 탭에서 다시 열 수 있습니다.

### 훈련
- **코치 모드** — 승률을 10% 이상 날리는 수를 두면 AI 응수를 보류하고
  배너로 **무르기**(직접 다시 시도), **이유 보기**(반박 수를 빨간 화살표로),
  **그대로 두기**를 제안합니다. 실수한 바로 그 순간의 즉각적인 피드백.
- **위협 레이더** — `T` 키를 누르고 있는 동안 상대가 노리는 것을 표시:
  내가 수를 쉰다면 상대가 둘 최선 수(빨간 화살표)와 잡힐 위기의 내 기물
  (빨간 원). 먼저 스스로 위협을 찾고, 그다음 확인하세요.
- **실수 지점에서 다시 두기** — 리뷰의 모든 놓침/실수/블런더에
  "⟲ 여기서 다시 두기" 버튼이 생깁니다. 게임을 `saves/`에 백업한 뒤 실수
  직전으로 되감아 엔진을 상대로 끝까지 둡니다.
- **전술 탭: 내 게임에서 나온 퍼즐** — 리뷰가 끝나면 명확한 유일 정답이
  검증된 실수들이 퍼즐 카드가 됩니다. 실제로 틀렸던 바로 그 포지션을 다시
  풀고, 카드마다 어느 게임에서 나왔는지 보여줍니다.
- **간격 반복** — 퍼즐은 라이트너 박스(1/3/7/21/60일)로 스케줄됩니다:
  깔끔하게 풀면 다음 박스로, 실패하면 내일 다시. 탭 배지가 복습 대기 수를
  보여주고 **복습하기** 버튼이 오늘의 큐를 진행합니다.
- **크로스 게임 실수 인사이트** — 리뷰된 모든 실수를 단계(오프닝/미들게임/
  엔드게임)와 패턴(기물 헌납, 메이트 놓침, 포크 놓침 등)으로 오프라인
  분류해 누적 기록하고, 라이브러리 탭이 "가장 잦은 패턴은 X" 식의
  피드백으로 집계해 보여줍니다.
- **퍼즐 러시 & 테마 연습** — 엄선된 Lichess 퍼즐 ~3,600개를 내장한 스타터
  팩(CC0, 완전 오프라인): **러시**는 3스트라이크/3분 안에 점점 어려워지는
  퍼즐을 풀며 최고 기록을 남기고, **테마 연습**은 포크·핀·백랭크 메이트 등
  모티프 하나를 쉬운 것부터 집중 훈련합니다 — 내 실수 덱이 차기 전 첫날부터
  전술 훈련량을 확보할 수 있습니다.

### 리뷰
- **chess.com 스타일 게임 리뷰** — 수 등급(**브릴리언트 `!!` / 훌륭한 수 `!`
  / 최선 / 북 무브 / 부정확 `?!` / 놓침 `✕` / 실수 `?` / 블런더 `??`**),
  진영별 정확도, 그리고 모든 등급 수에 대한 "최선은 …" 표시.
- 게임 전체의 **승률 그래프**와 주요 순간의 색깔 점 — 클릭하면 해당 수로
  이동합니다.
- **PGN 저장/불러오기** (평가값 포함). 되돌려 보기는 비파괴적이고, 과거
  포지션에서 새 수를 두면 그 지점에서 분기합니다.

### 오프닝 학습
- **ECO 트리 내장** — 이름 있는 라인 3,726개, 148개 계열, 검색 가능.
- **마스터 게임 통계** — TWIC 게임(양쪽 모두 2200+)에서 집계한 승/무/패
  비율과 수별 빈도. 순서가 바뀐 수순(transposition)도 자동 인식(EPD 키).
- **데모와 드릴** — 어떤 라인이든 한 수씩 재생해 보고, 백 또는 흑을 잡고
  드릴하세요(틀린 수에는 정답 화살표와 실패 카운터). 라인이 끝나면 버튼 한
  번으로 그 포지션에서 AI와 이어서 대국합니다.

### 인터페이스
- 다크 모던 GUI (PySide6/Qt), 드래그 앤 드롭 또는 클릭-클릭으로 기물 이동.
- **English / 한국어** — *옵션 → Language / 언어* 메뉴에서 전환.
- 플레이어, 난이도, 체크박스, 탭, 창 크기, 언어 설정을 기억합니다.
- 완전 오프라인, 무음.

## 조작법

| 동작 | 방법 |
|---|---|
| 수 두기 | 기물을 드래그하거나, 클릭 후 목표 칸 클릭 |
| 게임 되돌려 보기 | `←` / `→`, `Home` / `End`, 또는 ◀ ▶ 버튼 |
| 한 수 뒤로 (마우스) | 보드 우클릭 |
| 무르기 | `Ctrl+Z` 또는 무르기 버튼 |
| 새 게임 / 저장 / 불러오기 | `Ctrl+N` / `Ctrl+S` / `Ctrl+O` |
| 게임 전체 리뷰 | 사이드바의 "게임 분석" |
| 실수 다시 도전 | 수 상세 아래 "⟲ 여기서 다시 두기" |
| 코치 경고 켜기/끄기 | 사이드바의 "코치" 체크박스 |
| 상대 위협 확인 | `T` 키 홀드 (항상 켜려면 "위협" 체크박스) |
| 내 실수 재훈련 | 전술 탭 → "복습하기" |
| 퍼즐 러시 / 테마 연습 | 전술 탭 → "러시 시작" / "테마 연습" |
| 엔진 추천 수 표시 | 사이드바 "추천 수" 체크박스 (기본 꺼짐) |
| 보관된 게임 / 인사이트 | 라이브러리 탭 (끝난 게임 자동 저장) |
| 오프닝 드릴 | 오프닝 학습 탭 → 라인 선택 → "드릴 시작" |
| 언어 변경 | 옵션 메뉴 → Language / 언어 |

## 빌드

### Windows (자동, 권장)

[`.github/workflows/build-windows.yml`](.github/workflows/build-windows.yml)이
push/PR마다 실행됩니다: Stockfish 다운로드 → 코드 스모크 테스트 →
PyInstaller 빌드 → 빌드된 `.exe` 스모크 테스트.

- 모든 실행이 `ChessStudio-windows-x64-<버전>.zip`을 빌드 아티팩트로
  업로드합니다.
- 버전 태그를 푸시하면 zip이 첨부된 GitHub **릴리스**가 발행됩니다:

  ```bash
  git tag v1.7.0
  git push origin v1.7.0
  ```

### 로컬 빌드

```bat
build_windows.bat      REM Windows에서 -> dist\ChessStudio\ChessStudio.exe
```
```bash
./build_linux.sh       # Linux에서
```

PyInstaller는 크로스 컴파일이 안 되므로 각 OS에서 직접 빌드해야 합니다.
`dist/ChessStudio` 폴더 전체가 앱입니다 (Stockfish 포함, 오프라인 동작).

## 프로젝트 구조

```
main.py                  진입점
app/
  theme.py               다크 테마 팔레트 + Qt 스타일시트
  i18n.py                UI 번역 (English/한국어)
  eval_utils.py          엔진 점수 -> 승률 (Stockfish WDL 모델)
  engine_manager.py      Stockfish 프로세스 2개 (대국용/분석용) + 검증 작업
  game_controller.py     게임 상태, 코치 모드, 리뷰, 퍼즐 채굴
  board_widget.py        보드 렌더링, 화살표, 위협 오버레이
  sidebar.py             승률 바, 추천 수, 기보, 리뷰 컨트롤
  opening_book.py        내장 오프닝 DB 로더 (EPD 키)
  opening_tab.py         오프닝 학습 탭 (브라우저, 데모/드릴, 통계)
  puzzle_store.py        개인 전술 덱 (채굴된 실수 + 라이트너 스케줄링)
  puzzle_pack.py         내장 스타터 팩 로더 (러시 / 테마 연습)
  tactics_tab.py         전술 탭 (실수 덱, 퍼즐 러시, 테마 연습)
  game_library.py        끝난 게임의 PGN 자동 보관
  insights.py            크로스 게임 실수 분류 + 누적 로그
  library_tab.py         라이브러리 탭 (보관 게임 + 훈련 인사이트)
  main_window.py         전체 조립 (대국 / 오프닝 / 전술 / 라이브러리)
  data/openings.json.gz  오프닝 트리 + 마스터 게임 통계 (커밋됨)
tools/
  build_opening_data.py  오프닝 DB 재구축 파이프라인 (개발용, 네트워크 필요)
  build_puzzle_pack.py   퍼즐 스타터 팩 빌더 (개발용, 네트워크 필요)
engines/                 Stockfish 18 바이너리 (Linux / Windows)
saves/                   저장된 게임과 리플레이 백업 (PGN)
```

## 데이터 출처

- 러시/연습 퍼즐: [Lichess 퍼즐 데이터베이스](https://database.lichess.org/#puzzles)
  (CC0) — 레이팅 구간과 테마별로 샘플링한 검증된 퍼즐 ~3,600개.
  재구축: `python tools/build_puzzle_pack.py`.
- 오프닝 이름/라인: [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) (CC0)
- 승률 통계: [The Week in Chess](https://theweekinchess.com) 주간 PGN 아카이브
  (TWIC 1549–1648), 양쪽 모두 2200+ 레이팅인 게임만 집계. 아카이브를 무료로
  제공해 주는 TWIC에 감사드립니다.
- `app/data/openings.json.gz`는 저장소에 커밋되어 있어 일반 사용자는 재구축할
  필요가 없습니다. 갱신하려면: `python tools/build_opening_data.py all`.
